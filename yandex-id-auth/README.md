# Яндекс ID: вход с мобильного браузера

Ручное тестирование входа в аккаунт Яндекс ID на телефоне: по номеру, по логину и по лицу или отпечатку. Самостоятельный проект, не связан с работой в Яндексе.

## Окружение

| | |
|---|---|
| Устройство | Samsung Galaxy S24 FE |
| ОС | Android 16, One UI 8.5 |
| Браузер | Google Chrome 155.0.8059.81 |
| Сайт | ya.ru → страница входа passport.yandex.ru |
| Дата | 20.10.2026 |
| Аккаунты | собственные тестовые; коды и пароли в репозиторий не вносились |
| Справка | [Яндекс ID: вход в аккаунт](https://yandex.ru/support/id/ru/auth) |

## Что проверялось

- Вход по номеру телефона: пустой номер, номер не того формата, успешный вход, неверный код.
- Переход к другим способам входа и вход по логину: пустой и несуществующий логин.
- Неудачный вход по лицу или отпечатку.

**Не проверялось:** регистрация, восстановление доступа («Не могу войти»), вход в мобильном приложении.

## Результаты

| Показатель | Значение |
|---|---|
| Тест-кейсов | 10 |
| Pass | 10 |
| Fail | 0 |
| Находок | 1 |

Все сценарии входа работают: неверные данные не пускают в аккаунт, после трёх неверных кодов ввод временно блокируется, при сбое биометрии сервис предлагает войти по номеру.

**Находка:** [BUG-001](BUG-001-phone-mask-overflow.md) — поле номера пропускает лишние цифры сверх маски, а два варианта экрана входа реагируют на это по-разному: на одном флаг меняется на глобус, на другом остаётся российским. Неверный номер всё равно не принимается, поэтому это Minor.

## Ограничения

- Скриншоты экранов с номером телефона, логином и кодами (TC-AUTH-003, 004, 006, 008) не публикуются, результаты этих кейсов описаны текстом.
- Требования к формату номера в справке Яндекс ID не описаны, ожидания по длине номера основаны на маске поля и формате номеров РФ.
