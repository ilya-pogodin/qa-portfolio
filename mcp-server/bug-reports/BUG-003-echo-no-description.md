# BUG-003 — У инструмента echo отсутствует описание в списке инструментов

**Краткое описание:** в ответе `tools/list` у инструмента `echo` нет поля `description`, тогда как у всех остальных десяти инструментов оно заполнено

**Окружение:** macOS, Node.js v24.21.0; MCP-сервер из комплекта
**Severity:** Minor
**Priority:** Low
**Дата:** 27.09.2026
**Статус:** открыт

---

## Шаги воспроизведения

1. Запустить MCP-сервер
2. Запросить список инструментов:

```
curl -X POST http://localhost:4000/mcp -H "Content-Type: application/json" -H "Accept: application/json, text/event-stream" -d '{"jsonrpc":"2.0","method":"tools/list","params":{},"id":1}'
```

3. Сравнить состав полей у первого инструмента в списке и у остальных

## Ожидаемый результат

У каждого инструмента в списке заполнено поле `description` — по нему клиент понимает назначение инструмента.

## Фактический результат

У `echo` поле отсутствует:

```json
{"name":"echo","inputSchema":{...},"execution":{"taskSupport":"forbidden"}}
```

У остальных заполнено:

```json
{"name":"get-products","description":"Получить список всех товаров","inputSchema":{...}}
```

Проверены все одиннадцать инструментов: описание есть у десяти сгенерированных и отсутствует только у `echo`.

## Примечания

Причина в коде: регистрация `echo` выполнена сигнатурой без описания — имя, схема, обработчик. Сгенерированные инструменты регистрируются с описанием вторым параметром.

`echo` — демонстрационный инструмент из шаблона, в рабочей сборке его, вероятно, не должно быть вовсе. Если он остаётся, описание стоит добавить: клиент показывает пользователю список инструментов, и один пункт без пояснения выглядит незавершённым.

## Предлагаемая правка

Добавить описание при регистрации либо убрать демонстрационные `echo`-ресурс, инструмент и промпт из сборки, предназначенной для работы.
