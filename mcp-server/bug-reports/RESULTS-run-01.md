# Прогон 1 — результаты

**Дата:** 27.09.2026
**Окружение:** macOS, Node.js v24.21.0, npm 11.19.0
**Объект:** MCP-сервер, сгенерированный SwaggerHub по OpenAPI-спецификации
**Метод:** ручная отправка запросов через curl

**Ограничение текущего checkout:** исходный код MCP-сервера не включён в текущую версию репозитория. Ниже сохранены результаты исторического прогона, но повторить его из чистого клона нельзя до восстановления исходников.

**Важно про условия прогона.** Заглушка API не была запущена, внешний API недоступен (`ECONNREFUSED` на порт 4001). Поэтому проверен только путь ошибки; успешный сценарий работы инструментов остался непроверенным и выносится в следующий прогон.

## Что проверено и работает

**Запуск в историческом окружении.** В момент прогона `npm install` и `npm run dev` отрабатывали на Node 24. Конфигурация и исходный код этого сервера в текущем репозитории отсутствуют, поэтому запуск не воспроизводим из текущего checkout.

**Инструмент `echo`.** Запрос с сообщением «проверка» вернул `{"type":"text","text":"Tool echo: проверка"}`. Кириллица передаётся и возвращается без искажений.

**Валидация входных данных.** Вызов `add-product` без обязательного поля `price` отклонён с подробной ошибкой:

```
MCP error -32602: Input validation error: Invalid arguments for tool add-product:
[{ "expected": "number", "code": "invalid_type", "path": ["product","price"],
   "message": "Invalid input: expected number, received undefined" }]
```

Указаны путь к полю, ожидаемый тип и что пришло вместо него. Диагностика достаточная.

**Запрещённые методы HTTP.** GET на `/mcp` возвращает 405 и понятное сообщение с отсылкой к README:

```
HTTP/1.1 405 Method Not Allowed
{"jsonrpc":"2.0","error":{"code":-32000,"message":"Method not allowed. Use POST to interact with the MCP server. Follow README for details."},"id":null}
```

**Список инструментов.** `tools/list` возвращает одиннадцать инструментов: десять сгенерированных по спецификации плюс демонстрационный `echo`. У каждого заполнена `inputSchema` с обязательными полями.

## Что осталось непроверенным

**Успешный сценарий всех десяти инструментов.** Требует запущенной заглушки API. В этом прогоне заглушка не была поднята, поэтому каждый инструмент возвращал сообщение об ошибке, а не данные.

**Операции обновления и удаления.** По той же причине: без работающего API проверить, что данные действительно изменились, невозможно.

**Заказы.** Ни один из пяти инструментов по заказам не проверялся.

Всё перечисленное переносится в прогон 2.
