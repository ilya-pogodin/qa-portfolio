# BUG-001 — Сервер не поддерживает метод mcp.list_capabilities

**Краткое описание:** запрос с методом `mcp.list_capabilities` получает ошибку протокола −32601 (метод не найден). По комментарию в README проекта этот метод должен вызываться файлом `get_capabilities.ts`, но сам файл в репозитории отсутствует, поэтому утверждение «именно скрипт делает такой запрос» проверке не подлежит — подтверждён только факт отсутствия метода в протоколе.

**Окружение:** macOS, Node.js v24.21.0, npm 11.19.0; MCP-сервер из комплекта, `@modelcontextprotocol/sdk` 1.26
**Severity:** Major
**Priority:** Medium
**Дата:** 27.09.2026
**Статус:** открыт

---

## Шаги воспроизведения

1. Запустить MCP-сервер командой `npm run dev`
2. Дождаться строки `MCP Stateless Streamable HTTP Server listening on port 4000`
3. В отдельном окне терминала напрямую отправить запрос с методом `mcp.list_capabilities` (файл `get_capabilities.ts` для воспроизведения не запускался — его нет в репозитории; метод проверен вручную через curl):

```
curl -X POST http://localhost:4000/mcp -H "Content-Type: application/json" -H "Accept: application/json, text/event-stream" -d '{"jsonrpc":"2.0","method":"mcp.list_capabilities","params":{},"id":8}'
```

## Ожидаемый результат

Скрипт, поставляемый вместе с проектом, работает: возвращается список возможностей сервера.

## Фактический результат

```
event: message
data: {"jsonrpc":"2.0","id":8,"error":{"code":-32601,"message":"Method not found"}}
```

Код −32601 по спецификации JSON-RPC означает, что запрошенного метода не существует.

## Примечания

Метод `mcp.list_capabilities` в протоколе MCP отсутствует. Список инструментов отдаёт метод `tools/list` — он работает корректно, проверено в том же прогоне.

**Ограничение проверки.** Файл `get_capabilities.ts`, которым предположительно вызывается этот метод, в текущем состоянии репозитория отсутствует — как и весь исходный код MCP-сервера (`package.json`, `src/`, `tsconfig.json`). Проверить, какой именно запрос формирует скрипт, нельзя. Дефект подтверждён только на уровне протокола: метод `mcp.list_capabilities` не существует. Связь с конкретным скриптом — предположение из README, а не проверенный факт.

## Предлагаемая правка

Если скрипт `get_capabilities.ts` действительно вызывает `mcp.list_capabilities` — заменить метод на `tools/list` либо удалить скрипт из комплекта. Эту часть нельзя подтвердить без доступа к исходнику скрипта.
