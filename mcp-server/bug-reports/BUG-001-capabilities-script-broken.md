# BUG-001 — Приложенный к проекту скрипт вызывает несуществующий метод

**Краткое описание:** файл `get_capabilities.ts`, входящий в комплект проекта, обращается к методу `mcp.list_capabilities`, которого нет в протоколе; сервер отвечает ошибкой

**Окружение:** macOS, Node.js v24.21.0, npm 11.19.0; MCP-сервер из комплекта, `@modelcontextprotocol/sdk` 1.26
**Severity:** Major
**Priority:** Medium
**Дата:** 27.09.2026
**Статус:** открыт

---

## Шаги воспроизведения

1. Запустить MCP-сервер командой `npm run dev`
2. Дождаться строки `MCP Stateless Streamable HTTP Server listening on port 4000`
3. В отдельном окне терминала отправить запрос с методом, который использует скрипт `get_capabilities.ts`:

```
curl -X POST http://localhost:4000/mcp -H "Content-Type: application/json" -H "Accept: application/json, text/event-stream" -d '{"jsonrpc":"2.0","method":"mcp.list_capabilities","params":{},"id":8}'
```

## Ожидаемый результат

Скрипт, поставляемый вместе с проектом, работает: возвращается список возможностей сервера.

## Фактический результат

```
event: message
data: {"jsonrpc":"2.0","id":8,"error":{"code":-32601,"message":"Method not found"}}
```

Код −32601 по спецификации JSON-RPC означает, что запрошенного метода не существует.

## Примечания

Метод `mcp.list_capabilities` в протоколе MCP отсутствует. Список инструментов отдаёт метод `tools/list` — он работает корректно, проверено в том же прогоне.

Скрипт поставляется вместе с проектом и, судя по комментарию в первой строке, предназначен для получения возможностей сервера. В текущем виде он неработоспособен: любой, кто попробует им воспользоваться, получит ошибку.

## Предлагаемая правка

Заменить в `get_capabilities.ts` метод на `tools/list` либо удалить скрипт из комплекта, если он не нужен.
