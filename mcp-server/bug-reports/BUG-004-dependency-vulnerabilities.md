# BUG-004 — Уязвимости в зависимостях сгенерированного проекта

**Краткое описание:** установка зависимостей свежесгенерированного проекта сообщает о семи известных уязвимостях, три из них высокого уровня

**Окружение:** macOS, Node.js v24.21.0, npm 11.19.0
**Severity:** Major
**Priority:** Medium
**Дата:** 27.09.2026
**Статус:** открыт, требует детализации

---

## Шаги воспроизведения

1. Открыть терминал в папке проекта
2. Выполнить установку зависимостей:

```
npm install
```

3. Прочитать вывод после строки о количестве установленных пакетов

## Ожидаемый результат

Код, который генератор отдаёт пользователю, не содержит известных уязвимостей в зависимостях — либо о них сообщается при генерации.

## Фактический результат

```
added 128 packages, and audited 129 packages in 6s

7 vulnerabilities (1 low, 3 moderate, 3 high)

To address all issues, run:
  npm audit fix
```

Проект только что сгенерирован и ни разу не изменялся, дополнительные пакеты не устанавливались.

## Примечания

Важная деталь для воспроизведения: результат зависит от версии npm. На npm 10.9.7 та же установка сообщает об отсутствии уязвимостей, на npm 11.19.0 — о семи. Разница объясняется обновлением базы данных известных проблем, а не разным составом пакетов.

Это делает находку менее очевидной: разработчик генератора на старой версии npm проблему не увидит.

## Требует детализации

Не выполнена команда `npm audit` — она показывает, какие именно пакеты затронуты и какими уязвимостями. Без этого репорт неполон: непонятно, касаются ли проблемы рабочего кода или только инструментов разработки.

Также не проверено, устраняет ли их `npm audit fix` и не ломает ли при этом сборку.

## Предлагаемая правка

Обновить версии зависимостей в шаблоне генератора. Как минимум — предупреждать пользователя при генерации, что проект требует проверки зависимостей перед использованием.
