# Чек-лист: MCP-сервер

**Когда применять:** после генерации сервера из OpenAPI-спецификации, до передачи кода в работу.
**Цель:** проверить, что сгенерированные инструменты действительно работают, а не только компилируются.

---

## Что понадобится

| Что | Где взять |
|---|---|
| Node.js 18+ | nodejs.org, вариант LTS |
| Терминал | на macOS — «Терминал» в Программы → Утилиты |
| Заглушка API | [stub-api.js](stub-api.js) в этой папке |
| curl | предустановлен на macOS и Linux |

## Подготовка

1. Открыть терминал, перейти в папку проекта командой `cd путь/к/папке`.
2. Выполнить `npm install`, дождаться завершения.
3. Проверить версию Node: `node -v` — должно быть 18 или выше.
4. Открыть **второе** окно терминала (Cmd+N на macOS) — понадобится для заглушки.
5. Во втором окне перейти в ту же папку и выполнить `node stub-api.js`.
6. Вернуться в первое окно, запустить `MCP_API_URL=http://localhost:4001 npm run dev`.
7. Открыть **третье** окно — из него будут отправляться запросы.

Как отправить запрос: подставить нужное тело в команду

```bash
curl -X POST http://localhost:4000/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d 'ТЕЛО_ЗАПРОСА'
```

## Запуск и доступность

- [ ] `npm install` завершается без ошибок
- [ ] `npm run dev` выводит строку о запуске на порту 4000
- [ ] Заглушка выводит «Заглушка API слушает порт 4001»
- [ ] GET-запрос на `/mcp` возвращает 405 и понятное сообщение
- [ ] DELETE-запрос на `/mcp` возвращает 405
- [ ] Порт можно переопределить переменной `MCP_SERVER_PORT`

## Инструменты: успешный сценарий

Проверяется при поднятой заглушке.

- [ ] `get-products` возвращает список товаров
- [ ] `get-product` с существующим идентификатором возвращает товар
- [ ] `add-product` создаёт товар и возвращает его
- [ ] `update-product` обновляет товар
- [ ] `delete-product` удаляет товар и сообщает об успехе
- [ ] Те же шесть проверок для заказов: `get-orders`, `get-order`, `create-order`, `update-order`, `delete-order`

## Инструменты: негативные сценарии

- [ ] `get-product` с несуществующим идентификатором возвращает понятное сообщение
- [ ] `add-product` без обязательного поля `price` отклоняется с ошибкой валидации
- [ ] `add-product` с ценой в виде строки вместо числа отклоняется
- [ ] `create-order` с отрицательным количеством — проверить поведение
- [ ] Вызов несуществующего инструмента возвращает ошибку, а не падение сервера

## Обработка ошибок внешнего API

Проверяется при **остановленной** заглушке либо со значением `MCP_API_URL` по умолчанию.

- [ ] Недоступность API не роняет MCP-сервер
- [ ] Сообщение об ошибке позволяет понять причину: недоступен адрес, вернулся 404, вернулся 500
- [ ] Разные причины отказа дают разные сообщения
