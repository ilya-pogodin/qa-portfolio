# MCP-сервер — тестирование сгенерированного кода

**Объект:** MCP-сервер, сгенерированный SwaggerHub по OpenAPI-спецификации API товаров и заказов.
**Стек:** Node.js 18+, Express 5, TypeScript, `@modelcontextprotocol/sdk` 1.26.
**Что тестируется:** десять инструментов (CRUD по товарам и заказам) плюс демонстрационный `echo` из шаблона.

Это третий проект портфолио и единственный, где тестируется **работающий код**, а не документация. [ZooTicket](../zooticket) — разбор спецификации, [Rusau Learn](../rusau-learn) — чужое приложение без доступа к исходникам. Здесь есть и то и другое: спецификация, по которой сгенерирован код, и сам код, который можно запустить.

---

## Как запустить

### Что понадобится

Node.js версии 18 или выше. Проверить: `node -v`.
Если не установлен — скачать с nodejs.org, вариант LTS.

### Запуск сервера

```bash
npm install
npm run dev
```

Сервер поднимется на `http://localhost:4000/mcp`. В терминале появится строка
`MCP Stateless Streamable HTTP Server listening on port 4000`.

### Запуск заглушки API

Инструменты обращаются к внешнему API по адресу из переменной `MCP_API_URL`.
По умолчанию там `https://api.ilya.com` — несуществующий домен-заглушка, поэтому все запросы падают.

Чтобы инструменты можно было проверить на успешном сценарии, в проекте лежит [stub-api.js](stub-api.js) — минимальная реализация того же API на Express.

В отдельном окне терминала:

```bash
node stub-api.js
```

Заглушка слушает порт 4001 и отвечает на все десять операций, которые вызывают инструменты.

Затем перезапустить MCP-сервер, указав ему адрес заглушки:

```bash
MCP_API_URL=http://localhost:4001 npm run dev
```

### Отправка запроса

```bash
curl -X POST http://localhost:4000/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","method":"tools/list","params":{},"id":1}'
```

Ответ приходит в формате Server-Sent Events: строка `event: message`, затем строка `data:` с телом JSON-RPC.
