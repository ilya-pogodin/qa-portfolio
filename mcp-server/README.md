# MCP-сервер — артефакты тестирования

**Объект исходного тестирования:** MCP-сервер, сгенерированный SwaggerHub по OpenAPI-спецификации API товаров и заказов.  
**Заявленный стек:** Node.js, Express, TypeScript, `@modelcontextprotocol/sdk`.  
**Артефакты в этом репозитории:** отчёты двух прогонов, шесть баг-репортов, чек-лист и заглушка внешнего API.

> **Ограничение текущей версии репозитория.** Исходный код тестируемого MCP-сервера и его конфигурация (`package.json`, `src/`, `tsconfig.json`) сейчас не включены в репозиторий. Поэтому команды запуска MCP-сервера и результаты исторических прогонов нельзя независимо воспроизвести из чистого клона. Не запускайте `npm run dev`: соответствующего скрипта сейчас нет. Отчёты описывают прогоны, выполненные 27.09.2026, и не заменяют отсутствующий исходный код.

## Что можно запустить сейчас

В репозитории есть `stub-api.js` — упрощённая заглушка внешнего REST API. Она не является MCP-сервером и сама по себе не воспроизводит дефекты MCP-инструментов.

Требуется Node.js 18 или выше.

```bash
cd mcp-server
npm install
npm run stub
```

Заглушка слушает порт 4001. Доступны операции с товарами и заказами, описанные в файле [stub-api.js](stub-api.js).

Чтобы воспроизвести результаты MCP-прогонов, необходимо восстановить исходный код тестируемого MCP-сервера и его зависимости. До этого отчёты следует рассматривать как документацию ранее выполненного тестирования, а не как готовый к запуску стенд.

## Основные наблюдения из исторических прогонов

В отчётах зафиксированы проблемы с типом содержимого ответа, обработкой пустого ответа HTTP 204, диагностикой ошибок, описанием инструмента `echo` и вызовом неподдерживаемого метода. Статусы и выводы относятся к указанным в отчётах условиям выполнения и требуют повторной проверки после восстановления исходного кода.

**Ограничение покрытия:** инструменты заказов, обновление товара и обработка ответов 5xx в отчёте о прогоне 2 обозначены как непроверенные.
