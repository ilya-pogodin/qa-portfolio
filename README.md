## Проекты

### [rusau-learn](rusau-learn) — тестирование работающего приложения

Ручное тестирование образовательной платформы [Rusau Learn](https://learn.rusau.net): веб и мобильные приложения на iOS и Android. Тестирование ведётся по приглашению команды продукта, находки передаются разработчикам напрямую.

Девять находок: восемь дефектов и одно предложение по улучшению. Два блокирующих сценария, регрессия частичного исправления, расхождение поведения между платформами.

### [zooticket](zooticket) — проектирование тестов по спецификации

Система онлайн-продажи билетов в зоопарк. Учебный проект курса «Системный аналитик» (Aston): требования, UML-диаграммы, спецификация REST API в формате OpenAPI 3.0.

Здесь собрано всё, что строится вокруг спецификации: тест-кейсы, дефекты требований, найденные статическим тестированием, чек-листы и материалы по тестированию API вместе с рабочей коллекцией Postman.

### [templates](templates) — общие шаблоны

Формы тест-кейса, баг-репорта и универсального чек-листа регрессии. Не привязаны к проекту, используются в обоих.
