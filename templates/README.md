# Шаблоны

Общие формы, не привязанные к конкретному проекту.

| Файл | Когда применять |
|---|---|
| [test-case.md](test-case.md) | структура тест-кейса, правила оформления и разобранный пример |
| [bug-report.md](bug-report.md) | структура баг-репорта, разница severity и priority |
| [regression-checklist.md](regression-checklist.md) | регрессия перед релизом, подходит любому веб-продукту |

Начинать знакомство с портфолио удобно отсюда: шаблоны показывают, по каким правилам оформлены артефакты в проектах.
