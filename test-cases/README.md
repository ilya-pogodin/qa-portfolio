# Тест-кейсы

Наборы проверок по проекту ZooTicket — система онлайн-покупки билетов в зоопарк.

| Файл | Объект | Кейсов |
|---|---|---|
| [00-TEMPLATE.md](00-TEMPLATE.md) | шаблон, правила оформления и пример | — |
| [TC-payments-create.md](TC-payments-create.md) | POST /payments — создание платежа | 12 |
| [TC-payments-refund.md](TC-payments-refund.md) | POST /payments/{id}/refund — возврат | 10 |
| [TC-ticket-lifecycle.md](TC-ticket-lifecycle.md) | переходы состояний билета | 10 |

Начинать стоит с шаблона — он показывает структуру кейса и правила оформления на простом примере.

В каждом файле с кейсами есть разделы «Что понадобится» и «Установка и настройка» — чтобы по кейсам мог пройти человек, который видит проект впервые. Шаги расписаны до конкретных действий: какой запрос открыть, какое поле изменить, куда смотреть в результате.

Три кейса помечены как заблокированные: ожидаемый результат невозможно зафиксировать, пока не уточнены требования. Соответствующие вопросы вынесены в [дефекты требований](../bug-reports).
