## Как запустить коллекцию

1. Импортировать файл коллекции в Postman: File → Import.
2. Заполнить переменные `baseUrl` и `token` на вкладке Variables.
3. Запускать по порядку: запрос 01 сохраняет `paymentId` в переменную, остальные его используют.

Проверки написаны на вкладке Tests каждого запроса: код ответа, наличие обязательных полей, допустимые значения статуса, время ответа.

Запрос 02 (повтор с тем же ключом идемпотентности) проверяет только то, что новый платёж не создан. Ожидаемый код ответа не зафиксирован — в спецификации противоречие, см. [DEF-001](../bug-reports/DEF-001-idempotency-409.md).
