# Чек-листы ZooTicket

| Файл | Когда применять |
|---|---|
| [smoke-api-zooticket.md](smoke-api-zooticket.md) | после выкатки сборки, до основного прогона |
| [ui-ticket-purchase.md](ui-ticket-purchase.md) | проверка сценария покупки билета через сайт |

Универсальный чек-лист регрессии, не привязанный к проекту, лежит в [templates](../../templates/regression-checklist.md).

Чек-лист — список проверок без подробных шагов выполнения. Используется, когда нужно быстро пройти функциональность или когда писать полные тест-кейсы избыточно. Подробные пошаговые инструкции — это тест-кейсы, они в [test-cases](../test-cases).
