# Тест-кейсы ZooTicket

| Файл | Объект | Кейсов |
|---|---|---|
| [TC-payments-create.md](TC-payments-create.md) | POST /payments — создание платежа | 12 |
| [TC-payments-refund.md](TC-payments-refund.md) | POST /payments/{id}/refund — возврат | 10 |
| [TC-ticket-lifecycle.md](TC-ticket-lifecycle.md) | переходы состояний билета | 10 |

Форма кейса и правила оформления — в [шаблоне](../../templates/test-case.md).

В каждом файле есть разделы «Что понадобится» и «Установка», чтобы по кейсам мог пройти человек, который видит проект впервые. Шаги расписаны до конкретных действий: какой запрос открыть, какое поле изменить, куда смотреть в результате.

Три кейса помечены как заблокированные — ожидаемый результат невозможно зафиксировать, пока не уточнены требования. Соответствующие вопросы вынесены в [дефекты требований](../defect-reports).
