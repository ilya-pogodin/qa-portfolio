## Как запустить коллекцию

1. Импортировать файл коллекции в Postman: File → Import.
2. Заполнить переменные `baseUrl` и `token` на вкладке Variables.
3. Запускать по порядку: запрос 01 сохраняет `paymentId`. Перед исследовательскими сценариями возврата коллекция создаёт отдельные платежи и сохраняет их идентификаторы в отдельные переменные.

Проверки написаны на вкладке Tests каждого запроса: код ответа, наличие обязательных полей, допустимые значения статуса, время ответа.

Запрос 02 (повтор с тем же ключом идемпотентности) оставлен исследовательским: ожидаемое поведение требует уточнения, см. [DEF-001](../defect-reports/DEF-001-idempotency-409.md). Исследовательские запросы выводят фактический код и тело ответа в консоль и не должны выдавать формальный PASS, пока ожидаемый результат не согласован. Запрос 04 явно выполняется без авторизации.
