# BUG-12. В игре отсутствует кнопка «Послушать на Яндекс.Музыке»

- **Тест-кейс:** TC-06.2; TC-06.3
- **Классификация:** Дефект-кандидат
- **Severity:** Minor *(предварительно)*
- **Priority:** P2 *(предварительно)*
- **Статус:** Кандидат
- **Окружение:** Samsung Galaxy S24 FE 256 [SM-S721B/DS]; One UI 8.5, Android 16; версия приложения 26.87.
- **Выполнил:** Погодин Илья.

## Предусловия
Пользователь вошёл в приложение «Яндекс — с Алисой AI». Для сценариев навыка «Угадай песню» навык открыт, если это требуется тест-кейсом.

## Шаги воспроизведения
1. Открыть соответствующий раздел приложения.
2. Произнести голосовой запрос или выполнить действие из тест-кейса TC-06.2; TC-06.3.
3. Сравнить фактический ответ и интерфейс с ожидаемым результатом.

## Ожидаемый результат
Под карточкой ответа должна быть кнопка «Послушать на Яндекс.Музыке».

## Фактический результат
По заметкам, кнопки «Послушать» нет; кнопки лайка и дизлайка присутствуют.

## Обоснование и дальнейшая проверка
Подтвердить, предусмотрена ли кнопка для обеих распознанных песен в актуальной версии приложения.

## Доказательства
В исходных заметках фактические скриншоты, видеозапись, аудио и логи не приложены. Добавить их после повторного прогона.

> Severity и Priority предварительные. Записи со статусом «На уточнении» не считать подтверждёнными дефектами до согласования ожидаемого поведения.
