# BUG-09. Отсутствует элемент «Ещё картинки»

- **Тест-кейс:** TC-04.3
- **Классификация:** Дефект-кандидат
- **Severity:** Minor *(предварительно)*
- **Priority:** P2 *(предварительно)*
- **Статус:** Кандидат
- **Окружение:** Samsung Galaxy S24 FE 256 [SM-S721B/DS]; One UI 8.5, Android 16; версия приложения 26.87.
- **Выполнил:** Погодин Илья.

## Предусловия

Выполнены TC-04.1 и TC-04.2: открыт просмотр изображений, затем открыто одно из изображений.

## Шаги воспроизведения

1. Вернуться из открытого изображения в приложение Алисы.
2. Проверить, отображается ли элемент или ссылка «Ещё картинки».
3. Если элемент есть, нажать его и проверить переход к результатам по тому же запросу.
4. Сохранить скриншот экрана после возврата в приложение.

## Ожидаемый результат
После возврата в приложение элемент «Ещё картинки» должен открывать Яндекс.Картинки по выбранному запросу.

## Фактический результат
Элемент/ссылка «Ещё картинки» отсутствует; переход проверить не удалось.

## Обоснование и дальнейшая проверка
Ожидаемый следующий шаг сценария недоступен. Приложить скриншот экрана после возврата из открытого изображения.

## Доказательства
В исходных заметках фактические скриншоты, видеозапись, аудио и логи не приложены. Добавить их после повторного прогона.

> Severity и Priority предварительные. Записи со статусом «На уточнении» не считать подтверждёнными дефектами до согласования ожидаемого поведения.
