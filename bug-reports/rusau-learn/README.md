## Наблюдения по итогам

Четыре из девяти находок относятся к онбордингу — это самая проблемная область на момент тестирования. Три дефекта касаются навигации по шагам (пропуск, задержка отрисовки, отсутствие кнопки), один — оформления. Для сценария, который видит каждый новый пользователь, концентрация высокая.

BUG-004 — наглядный пример расхождения severity и priority. Само по себе нечитаемое время в статус-баре ничего не ломает, но это первый экран после регистрации, его видят все новые пользователи, поэтому приоритет выше серьёзности.

BUG-007 показывает разницу между платформами на одном контенте: в вебе артефакта нет, в мобильном приложении есть. Такие расхождения обычно указывают на реализацию плеера, а не на исходный файл.

## Что осталось невыясненным

Версии приложений на момент находок не зафиксированы — поле «Окружение» заполнено тем, что известно. При дальнейшем тестировании версию надо снимать до начала работы.
