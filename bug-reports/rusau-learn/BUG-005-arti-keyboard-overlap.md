# BUG-005 — Клавиатура перекрывает поле ввода в ИИ-помощнике «Арти»

**Краткое описание:** при открытии «Арти» экранная клавиатура закрывает поле ввода, поднять его прокруткой невозможно

**Окружение:** Android, Samsung Galaxy S24 FE; версия приложения не зафиксирована
**Severity:** Critical
**Priority:** High
**Дата:** 24.09.2026
**Статус:** открыт

---

## Шаги воспроизведения

1. Открыть приложение
2. Перейти в раздел «Арти» через нижнюю панель
3. Нажать на поле «Спросите Арти» — открывается клавиатура
4. Попробовать увидеть вводимый текст, в том числе прокруткой содержимого вверх

## Ожидаемый результат

При открытии клавиатуры содержимое сдвигается вверх, поле ввода остаётся видимым, пользователь видит набираемый текст.

## Фактический результат

Клавиатура перекрывает поле ввода. Сдвинуть содержимое вверх не удаётся — область остаётся на месте. Набирать текст вслепую.

## Обходной путь

Открыть «Арти» в полноэкранном режиме — там поле ввода видно.

## Примечания

Блокирует основной сценарий работы с ИИ-помощником в обычном режиме. Пользователь, не знающий про полноэкранный режим, сочтёт функцию неработающей.

Второй дефект в том же элементе — см. [IMP-001](IMP-001-arti-input-autosize.md) про поведение поля при длинном тексте. Имеет смысл посмотреть обработку клавиатуры и размеров поля одним заходом.

## Требует проверки

Воспроизводится ли на других моделях Android и на iOS. Пока проверено на одном устройстве, поэтому нельзя сказать, общий это дефект или специфика оболочки Samsung.
