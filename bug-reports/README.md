# Дефекты

Находки статического тестирования — проверки спецификации ZooTicket Payments API v1.1.0 без запуска системы.

| ID | Проблема | Severity |
|---|---|---|
| [DEF-001](DEF-001-idempotency-409.md) | противоречие между идемпотентностью и кодом 409 | Major |
| [DEF-002](DEF-002-amount-validation.md) | нет ограничений на сумму и валюту | Major |
| [DEF-003](DEF-003-refund-rules.md) | не описаны правила частичного и повторного возврата | Major |
| [DEF-004](DEF-004-webhook-replay.md) | подпись webhook не защищает от повторной отправки | Major |

[TEMPLATE.md](TEMPLATE.md) — шаблон баг-репорта для дефектов, найденных в работающей системе.

Дефект требований отличается от баг-репорта: он описывает проблему в документе, а не в поведении программы. Поэтому вместо шагов воспроизведения здесь вопросы к аналитику и предлагаемая правка.
